# Project Metadata

This directory contains project metadata files used for repository management, SEO, and GitHub configuration. These files are not part of the development documentation.

## Contents

- **GITHUB_TOPICS.md** - GitHub repository topics for discoverability
- **PROJECT_DESCRIPTION.md** - Project description for GitHub repository settings
- **SEO_METADATA.md** - SEO keywords and metadata for improved search visibility

## Purpose

These files help with:
- Repository discoverability on GitHub
- Search engine optimization
- Project categorization and tagging
- Repository metadata management

## Note

These files are administrative and do not contain technical development information. For development documentation, see the main `docs/` directory.
